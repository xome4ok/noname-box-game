# Instructions for a fellow playtester

If you're reading this, you're probably going to playtest this, or feel free to ignore and move on with your life.

## The only important thing

i'd like to ask you - when you play it, note your experience and tell me about it.

## The other only important thing

When you feel like closing the game, please stop!

Go to **Pause menu > Debug stats**, press **Copy** to copy the game log to clipboard and send it to me.
